# Single-Page-CV
The goal of this project is to learn how to create a structured, single-page CV using only HTML

## Features
This website contains following sections: 
-Personal information
-Technical skills as a front end engineer
-Educational qualifications
-Internship experiance and projects 
-My linkedin and github profile links

## Technologies Used
HTML5

## How to Run the Project
1.Clone this repository
    git clone https://github.com/isminarifa-pixel/Single-Page-CV.git
2.Enter project folder
    cd Single-Page-CV
3.open index.html in any web browser
